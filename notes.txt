[Problem 1 (Particle Representation)]

Goal: To create a library that has all the functions given by the API in problem 1.

Approach: Firstly, construct the class Blob and use the constructor to assign the instance variables x and y which are 
the locations of the center of mass of the particles as well as the instance variable pixels which would be the amount of
pixels in a particle. The add method finds the pixel at the location, and adds it to the blob as well as adding one to 
the pixel. This helps with the mass() method which returns the value of instance variable pixels, as the total amount
of pixels in a particle is considered the mass of the particle in this program. The DistanceTo method uses the Euclidean
Distance equation to find the distance between two center of masses.
